# 订单系统全流程测试用例

> 目标：覆盖订单系统从登录、录单、收款、配货、发货、完成、取消到异常场景的完整链路。
> 执行基线：`blade-admin` + `blade-backend` + MySQL + Redis 本地联调环境。
> 当前维护日期：2026-04-19

---

- 登录与权限初始化

## 六、当前已发现问题

### BUG-ORDER-001

- 标题：后端声明启用 Flyway，但构建依赖缺失
- 现象：新测试库启动后没有任何业务表，登录接口直接返回 `500`
- 影响：订单全流程测试在登录前就被阻断
- 处理状态：已定位，已补充 `flyway-core` 和 `flyway-mysql` 依赖

### BUG-ORDER-002

- 标题：JDBC 配置未兼容 MySQL 8 默认认证策略
- 现象：`POST /api/auth/login` 与 `OrderControllerTest` 早期均返回 `500`
- 影响：订单全流程 UI/E2E 与接口测试均无法获取 token
- 处理状态：已定位，`application.yml` 与 `application-test.yml` 已补 `allowPublicKeyRetrieval=true`

### BUG-ORDER-003

- 标题：测试环境禁用了 Flyway，导致回归测试无法在空库自举
- 现象：`application-test.yml` 中 `spring.flyway.enabled=false`
- 影响：`OrderControllerTest` 对空库运行时无法自动建表
- 处理状态：已定位，已改为开启迁移

### BUG-ORDER-004

- 标题：迁移脚本版本号冲突
- 现象：Flyway 校验时报 `Found more than one migration with version 8`
- 影响：后端无法启动，订单链路无法测试
- 根因：存在重复版本脚本 `V8__*` 与 `V12__*`
- 处理状态：已定位，已将重复脚本重编号为 `V8_1`、`V12_1`

### BUG-ORDER-005

- 标题：`V3__product_module.sql` 初始化数据字段与建表结构不一致
- 现象：迁移到 V3 时失败，报 `Unknown column 'price' in 'field list'`
- 影响：后端无法完成基础商品模块建表
- 根因：`product` 表无 `price` 字段，但初始化插数仍写入 `price`
- 处理状态：已定位，已修复插数字段

### BUG-ORDER-006

- 标题：`V7__order_table_rename.sql` 假定目标表已存在，但重命名 SQL 被注释
- 现象：迁移到 V7 时失败，报 `Table 'blade_project.sale_order_item' doesn't exist`
- 影响：订单重构迁移中断，后续配货/发货链路全部不可测
- 根因：脚本直接更新 `sale_order_item`，却没有执行 `order_item -> sale_order_item` 重命名
- 处理状态：已定位，已改为按表存在性条件自动重命名

### BUG-ORDER-007

- 标题：`V13__sys_user_role_fix.sql` 使用了不兼容 MySQL 8 的批量 `ADD COLUMN IF NOT EXISTS` 语法
- 现象：迁移到 V13 时失败，报 SQL 语法错误
- 影响：权限表结构修复中断，登录和菜单权限链路不可验证
- 根因：脚本把多列新增写成单条 `ADD COLUMN IF NOT EXISTS (...)`
- 处理状态：已定位，正在改为逐列兼容写法

### BUG-ORDER-008

- 标题：后端开发启动依赖被无关测试编译失败阻断
- 现象：`mvn spring-boot:run` 会在 `DashboardServiceTest` 上编译失败
- 影响：后端开发启动需要额外使用 `-Dmaven.test.skip=true`，影响联调效率
- 根因：`DashboardServiceTest` 仍调用旧接口签名
- 处理状态：已定位，待单独修复
