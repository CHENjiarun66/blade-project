## 手工冒烟清单（需运行后端 + 移动端 dev server）

启动方式：隔离库环境变量见最终交付报告；`cd blade-mobile && npm run dev`。

| # | 步骤 | 预期 |
|---|---|---|
| 1 | 登录 → 订单列表 | 列表按新状态标签显示；Tab 为：全部/已确认/待配货/配货中/待发货/已发货/已完成/已取消 |
| 2 | 切换"待发货"Tab | 仅显示 READY_TO_SHIP 的新订单；历史未迁移行只在"全部"出现 |
| 3 | 打开一笔新模型订单详情 | 显示收款/结清/履约方式 Chip；按钮只出现 allowedActions 中的动作 |
| 4 | 打开一笔历史未迁移订单详情 | 显示"历史未迁移"标签；收款状态按旧字段回退展示 |
| 5 | 对未结清订单点"确认收款" | 全额收款后收款 Chip 变为"已结清"；按钮消失 |
| 6 | 对已结清订单尝试发货（未配货） | 后端拒绝并提示"订单没有配货计划"（不出现前端按钮误触发的场景由 allowedActions 保证） |
| 7 | 创建新订单（订单创建页） | 提交不携带任何数字状态；创建后详情显示 UNPAID |
| 8 | 老版本移动端（旧构建）读取新订单 | 新增字段被忽略，不崩溃（旧字段由兼容投影返回） |

## 已知边界

- 历史未迁移行不参与按履约状态的 Tab 过滤（其新字段为空）；全部列表可见。
- 移动端不发起新增的退款/冲销/拆分动作（PC 专属）；后端对这些端点的权限校验独立生效。
