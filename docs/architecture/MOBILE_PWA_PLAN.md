# 移动端的维护范围与后续计划

> 文档状态：现行范围说明。核对：2026-11-02。旧 UI/实施设想见 [历史方案](../archive/designs/MOBILE_PWA_ORIGINAL.md)。

移动端已有 Vue 3/PWA 骨架、部分订单和库存页面，以及新订单状态的兼容展示。当前以维护现有功能为主，新增页面排在订单、库存和真实业务验收之后。

## 当前实现

依赖以 `blade-mobile/package.json` 和 lockfile 为准：Vite 8、Vuetify 4、Pinia 3、Vue Router 4。共享类型来自 `packages/types`。技术选型表不能覆盖实际构建依赖。

源码存在不等于已部署独立移动服务。NAS 当前对外网页来自 blade-admin，`/catalog` 也属于 PC 构建；移动端触控、PWA 更新和离线策略仍要独立验收。

## 当前优先级

- 维护现有登录、订单查询、收款/履约状态展示和库存页面
- 核对实际 JWT、错误码处理与 PC 端差异
- 搜索、扫码、库存调整、商品编辑、SKU 配置及图表继续保留在任务账本，新增开发后置
- 旧方案里的考勤、通知、审批、批次和积分不构成当前排期

优先级以 [项目范围](../PROJECT_SCOPE.md) 为准，单项进度以 [任务账本](../03-TASKS.md) 为准。当前没有正在执行移动端新功能的已认领任务。
