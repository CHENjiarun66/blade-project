# AI 开发工作流程

> 记录如何使用 Claude Code 等 AI 工具进行纯 AI 开发。

---

## 一、工具链

| 工具 | 角色 | 使用场景 |
|------|------|---------|
| **Claude Code** | 主力开发 | 项目初始化、代码生成、调试、架构搭建 |
| **Windsurf** | 辅助 | Agent 模式跑完整功能、并行验证 |
| **Stitch** | UI 设计 | 移动端 UI 设计 |
| **Gemini** | 静态生成 | 基于 Stitch 设计稿生成静态页面 |

---

## 二、工作流程

### 2.1 需求提出

```
用户 → 04-REQUISITION_LOG.md 提出需求
```

### 2.2 需求确认

```
AI 分析 → 给出方案 → 用户确认 → 同步到 02-PRD.md → 拆解到 03-TASKS.md
```

### 2.3 开发执行

```
AI 从 03-TASKS.md 领取任务 → 自主开发 → 更新任务状态 → 通知用户
```

### 2.4 交接同步

```
任务完成 → 更新 03-TASKS.md → 更新 05-CHANGELOG.md
```

---

## 三、Claude Code 常用指令

| 指令 | 说明 |
|------|------|
| `/help` | 查看帮助 |
| `/branch [name]` | 创建分支 |
| `/effort [low/medium/high]` | 设置任务复杂度 |
