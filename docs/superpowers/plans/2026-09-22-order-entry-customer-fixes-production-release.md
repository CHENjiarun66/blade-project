> 原则：本次不自动合并或删除任何历史订单。

## 1. 发布范围

1. 快速录单右侧增加固定订单原图对照栏，支持上传最多 10 张、原图展示、缩放、切换和删除；左侧录单功能与草稿暂存流程不变。
2. 正式订单在以下条件同时满足时允许修改客户快照、商品明细、数量、售价和运费：
   - 新状态字段已迁移且订单状态为 `CONFIRMED`；
   - `fulfillment_mode=UNDECIDED`，尚未进入配货/发货；
   - 收款状态为 `UNPAID` 或 `PARTIAL`；
   - 当前操作人拥有 `btn:order:edit`。
3. 修改后订单应收不得低于当前净实收；`SETTLED`、已进入履约、已退款/退货/核销等订单不开放结构编辑。
4. 草稿确认时，新客户可以只保留订单客户快照；无效、已删除或跨租户的 `customer_id` 自动解除关联，不阻断生成正式订单。空名称按“散客”处理。
5. 客户商品偏好由“SKU 行数”改为按订单明细 `quantity` 累计；客户订单列表接入分页，并补充纸质单号与订单日期。

## 6. 回滚

- 应用异常：切回发布前镜像/tag；本次接口字段为向后兼容增量，旧应用可继续读取已有数据。
- 数据库迁移异常：停止应用启动，保留失败现场；按 Flyway 记录决定 repair 或从已验证备份恢复，不在生产手工猜测修表。
- 文件异常：恢复 uploads 与 `file_storage`/`file_business_bind` 同一时间点快照，禁止只恢复其中一侧。
- 业务数据异常：停止继续编辑，不删除订单；根据发布前关键表备份和状态/财务日志制定定向修复。
