## 一、项目概览

### 1.1 这是什么项目

BladeProject 是一个**纯 AI 驱动开发**的项目：
- 你只负责提需求和验收
- AI（Claude Code）负责写代码
- 目标是实现：订单系统、库存系统、看板系统（移动端 PWA + 后端）

### 1.2 技术栈

| 层级 | 技术 |
|------|------|
| 移动端 | Vue3 + PWA（iPhone/iPad/Android 可用） |
| 后端 | Spring Boot 3 + MySQL |
| AI 工具 | Claude Code |

### 1.3 相关路径

| 资源 | 路径 |
|------|------|
| 项目根目录 | `../` |
| 移动端代码 | `../blade-mobile/` |
| 后端代码 | `../blade-backend/` |
| 原 Blade 项目 | `/Users/chenjiarun/Documents/Blade/` |

## 二、如何提出新需求

### 2.1 方式一：直接告诉我（推荐）

直接在这个对话窗口告诉我你的需求，比如：

```
"我想给订单列表加一个导出功能"
"新增一个员工管理模块"
"修改订单状态的流程"
```

我会分析需求，然后记录到需求讨论区，最终更新到 PRD。

### 2.2 方式二：直接编辑文档

如果你想更精确地描述需求，可以直接编辑：

```
./04-REQUISITION_LOG.md
```

在底部追加你的需求，格式：

```markdown
### [日期] 需求 #N - {需求标题}

**提出者**：用户

**需求描述**：
{具体描述你想要的功能}

**期望效果**：
{你希望实现后的效果}
```

### 2.3 需求提出模板（可选）

如果你想更规范地提出需求，可以用这个模板：

```
## 需求标题

### 背景
为什么需要这个功能？

### 需求描述
- 功能点 1
- 功能点 2
- 功能点 3

### 验收标准
- 标准 1
- 标准 2

### 优先级
P0（紧急）/ P1（重要）/ P2（一般）
```

## 四、如何验收功能

### 4.1 AI 通知你

AI 完成一个功能后会通知你，比如：

```
"订单列表页已完成，任务状态已更新到 03-TASKS.md
功能包括：
- 订单号、客户名、金额、状态、下单时间
- 支持按状态筛选
- 支持分页
请验收：运行 http://localhost:5173"
```

### 4.2 验收时检查

- [ ] 功能是否按需求实现？
- [ ] 界面是否符合预期？
- [ ] 是否有报错？
- [ ] 有没有明显的 bug？

### 4.3 验收结果反馈

如果有问题，直接告诉我：

```
"订单列表页有个问题：分页不生效"
"订单状态筛选的选项少了'已取消'这个状态"
```

我会立即修复。

如果验收通过：

```
"验收通过，可以继续下一个任务了"
```

## 五、如何提出问题/反馈

### 5.1 功能不符合预期

```
"订单状态筛选的顺序不对，应该是：待处理 → 已确认 → 进行中 → 已完成 → 已取消"
```

### 5.2 发现 bug

```
"有个 bug：新建订单后，列表页没有显示新订单，需要手动刷新"
```

### 5.3 想调整需求

```
"之前说的那个需求有点变化，我想改成..."
```

### 5.4 想暂停/终止任务

```
"先停一下订单详情页的开发，先做库存列表"
```

## 七、常见问题

### 7.1 AI 开发的代码质量如何？

AI 生成的代码：
- 遵循最佳实践
- 有类型标注（TypeScript）
- 有错误处理
- 有适当的注释

但仍需人工验收，因为 AI 可能不完全理解业务细节。

### 7.2 AI 遇到问题会怎么办？

AI 会：
1. 先尝试自己解决
2. 查文档（TROUBLESHOOTING.md）
3. 如果解决不了，会在任务清单标注 ❌阻塞，然后通知你

### 7.3 能同时做多个任务吗？

可以。AI 可以并行处理多个独立任务。但为了保证质量，建议一次专注一个模块。

### 7.4 交接给其他 AI 需要做什么？

不需要做什么。只需告诉新 AI：

```
请先阅读 ./01-README.md
```

新 AI 会自动加载所有规范和上下文。
