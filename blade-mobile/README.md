# Blade Mobile

服装订单管理系统移动端前端

## 技术栈

- Vue 3.4 + TypeScript 5
- Vite 8
- Vuetify 3
- Vue Router 4
- Pinia
- PWA

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build
```

## 目录结构

- `src/api/` - API 调用
- `src/router/` - 路由配置
- `src/stores/` - 状态管理
- `src/views/` - 页面组件
- `src/types/` - TypeScript 类型
- `src/plugins/` - 插件配置
