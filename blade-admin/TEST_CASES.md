## 四、UX 视觉检查清单 (BA-004-UX)

### 4.1 视觉一致性检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 主色调一致性 | ✅ | `#408aee` 品牌蓝在 Logo、按钮、链接、验证码等处统一使用 |
| 辅助色层次 | ⚠️ | 灰色系 `#2c2f31`（深）、`#595c5e`（中）、`#abadaf`（浅）基本一致，但缺少次要强调色 |
| 字体层级 | ✅ | 标题 28px/22px、正文 14px/15px、标签 12px，层级清晰 |
| 间距系统 | ✅ | 表单项 gap 24px、标签与输入框 gap 8px、内边距 40px/16px/14px，节奏一致 |
| 圆角一致性 | ✅ | 组件圆角 10px/12px，装饰性元素 12px，视觉统一 |
| 图标尺寸 | ✅ | input-icon 20x20、brand-icon 40x40、button-icon 20x20，比例协调 |

**潜在问题**：
- 验证码区域背景 `#dfe3e6` 与整体灰色调略有色相偏差（偏冷），可考虑与输入框背景 `#f3f5f7` 更统一

### 4.2 交互反馈检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 按钮悬停效果 | ✅ | `translateY(-1px)` + 背景变深，有明确反馈 |
| 按钮点击效果 | ✅ | `scale(0.98)` 下沉反馈，与悬停区分 |
| 按钮禁用态 | ✅ | `opacity: 0.7` + `cursor: not-allowed`，状态可辨 |
| 输入框焦点 | ✅ | `box-shadow` 外发光环，无边框色变化，焦点清晰 |
| 输入图标焦点态 | ✅ | 图标颜色从 `#abadaf` → `#408aee`，提供视觉引导 |
| 密码显示切换 | ⚠️ | 使用 emoji `👁` / `👁‍🗨`，在部分字体下可能渲染不一致，建议用 SVG 图标替代 |
| 链接悬停 | ✅ | 颜色从 `#408aee` → `#3577cd`，underline 过渡 |

**潜在问题**：
- 密码切换按钮使用 emoji，在某些操作系统/浏览器下显示效果不一致

### 4.3 验证码显示区域

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 验证码背景色 | ⚠️ | `#dfe3e6` 与输入框背景 `#f3f5f7` 差异较大，视觉不够融合 |
| 验证码字体 | ✅ | 20px italic 粗体，字母间距 4px，与背景形成对比 |
| 验证码点击区 | ✅ | 整个区域可点击，有 `cursor: pointer`，有 hover 反馈 |
| 刷新反馈 | ⚠️ | 刷新时无动画过渡，视觉跳跃感 |

**潜在问题**：
- 验证码区域背景与输入框不一致，视觉风格分裂
- 验证码刷新是瞬时替换，无淡入淡出过渡

### 4.4 响应式布局检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 容器最大宽度 | ✅ | `max-width: 480px`，在大屏幕上居中显示 |
| 移动端适配 | ⚠️ | 未测试极小屏幕（320px）下的内边距 `padding: 40px` 是否溢出 |
| 背景装饰响应 | ⚠️ | 装饰圆 fixed 定位，在移动端可能超出视窗 |
| 长标题处理 | ✅ | "服装订单管理系统" 在 480px 内不会溢出 |

**潜在问题**：
- 移动端 320px 宽度下，login-card 的 40px 内边距 + 表单 gap 24px × 4 可能导致内容溢出
- 验证码区域在窄屏下可能换行

### 4.5 可访问性检查

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 颜色对比度 | ✅ | 主色 `#408aee` 在白底 `#fff` 上对比度约 4.5:1，符合 WCAG AA |
| 文字对比度 | ✅ | 正文 `#2c2f31` / `#595c5e` 在白底对比度 > 7:1 |
| 表单 label | ✅ | 所有输入框有对应 label 标签 |
| 焦点可见性 | ⚠️ | 仅输入框有 focus ring，按钮/链接无可见焦点样式（键盘用户） |
| 链接可识别性 | ✅ | 链接有下划线（hover），颜色与正文区分 |
| 验证码可访问性 | ⚠️ | 验证码使用纯视觉显示，屏幕阅读器无法读取（但验证码本身不宜对机器可读） |

**潜在问题**：
- 键盘 Tab 导航时，按钮 `.login-button`、链接 `.forgot-link`、`.footer-link` 缺少焦点样式
- 验证码图片对屏幕阅读器是装饰性内容，建议 `aria-label` 说明

### 4.6 动画和过渡效果

| 检查项 | 状态 | 说明 |
|--------|------|------|
| 过渡时长 | ✅ | 统一使用 `0.2s`，节奏一致 |
| 缓动函数 | ⚠️ | 默认 `ease`，未显式声明，部分浏览器可能有差异 |
| Logo 悬停动画 | ✅ | `scale(1.05)` + `0.2s`，平滑 |
| 按钮状态过渡 | ✅ | hover/active 状态有过渡 |
| 验证码刷新 | ❌ | 无过渡动画，瞬间替换 |

**潜在问题**：
- 验证码刷新时无过渡效果，体验略显生硬
- 所有过渡未声明 `timing-function`，在低性能设备上可能跳帧

### 4.7 表单与错误提示

| 检查项 | 状态 | 说明 |
|--------|------|------|
| Element Plus 消息提示 | ✅ | 使用 `ElMessage` 组件，视觉统一 |
| 错误提示位置 | ✅ | 消息从顶部居中弹出，不干扰表单 |
| 必填提示 | ⚠️ | 无字段级必填星号标记，用户依赖提交后提示 |
| 占位符文本 | ✅ | 占位符文字颜色 `#abadaf`，与用户输入颜色 `#2c2f31` 区分 |

**潜在问题**：
- 表单字段缺少必填标记（`*`），仅在提交时提示，用户体验不够直观

## 五、UX 视觉 Bug 汇总

### 严重程度：高

| Bug ID | 描述 | 位置 | 建议修复 |
|--------|------|------|----------|
| UX-001 | **键盘导航无焦点样式** — Tab 键切换到按钮/链接时，无可见焦点指示 | `.login-button`, `.forgot-link`, `.footer-link` | 添加 `:focus-visible { outline: 2px solid #408aee; outline-offset: 2px; }` |
| UX-002 | **验证码刷新无过渡动画** — 点击刷新时验证码文字瞬间替换，视觉跳跃 | `.captcha-text` | 验证码刷新时增加淡入淡出动画（opacity 0→1，300ms） |

### 严重程度：中

| Bug ID | 描述 | 位置 | 建议修复 |
|--------|------|------|----------|
| UX-003 | **密码切换按钮使用 emoji** — `👁` / `👁‍🗨` 在不同字体/系统下渲染不一致 | `.password-toggle` | 替换为 lucide-vue-next 或其他 SVG 图标组件 |
| UX-004 | **验证码背景色与输入框不一致** — 验证码 `#dfe3e6` 与输入框 `#f3f5f7` 色系分裂 | `.captcha-code` | 将验证码背景调整为与输入框一致的 `#f3f5f7` |
| UX-005 | **移动端内边距溢出风险** — 40px 内边距在极窄屏（320px）下可能导致溢出 | `.login-card` | 添加 `@media (max-width: 480px)` 将内边距缩小至 24px |
| UX-006 | **表单无字段级必填标记** — 用户无法快速识别哪些字段为必填 | 所有 `.form-group` | 在 label 文本后添加红色 `*` 星号 |

### 严重程度：低

| Bug ID | 描述 | 位置 | 建议修复 |
|--------|------|------|----------|
| UX-007 | **过渡函数未显式声明** — 使用浏览器默认 ease，不同浏览器可能有差异 | 全局 | 统一添加 `transition-timing-function: ease` 或自定义贝塞尔曲线 |
| UX-008 | **验证码区域 hover 效果偏弱** — 仅背景色变深，缺少 scale/shadow 等更明显反馈 | `.captcha-code` | 可增加轻微 `transform: scale(1.02)` 增强可点击感知 |
| UX-009 | **背景装饰在移动端可能溢出** — 256px/320px 圆形 fixed 定位，小屏上可见区域外 | `.bg-decoration-1/2` | 添加移动端隐藏或缩小尺寸的媒体查询 |

import { test, expect } from '@playwright/test';

test.describe('登录功能自动化测试', () => {

    // 验证跳转
    await expect(page).toHaveURL(/dashboard/);
    await expect(page.locator('.el-message')).toContainText('登录成功');
  });

  test('LC-007: 表单未填写完整', async ({ page }) => {
    await page.fill('input[placeholder="输入公司 ID 或名称"]', 'test_tenant');
    // 故意不填写账号
    await page.fill('input[placeholder="••••••••"]', 'admin123');

    await page.click('button[type="submit"]');

    await expect(page.locator('.el-message')).toContainText('请填写完整登录信息');
  });

  test('LC-016: 密码显示隐藏切换', async ({ page }) => {
    const passwordInput = page.locator('input[placeholder="••••••••"]');
    await passwordInput.fill('test123');

    // 初始状态为密码类型
    await expect(passwordInput).toHaveAttribute('type', 'password');

    // 点击显示按钮
    await page.click('.password-toggle');
    await expect(passwordInput).toHaveAttribute('type', 'text');

    // 再次点击隐藏
    await page.click('.password-toggle');
    await expect(passwordInput).toHaveAttribute('type', 'password');
  });

  test('LC-021: 网络错误处理', async ({ page }) => {
    // 使用 Playwright 拦截请求模拟网络错误
    await page.route('**/api/auth/login', (route) => {
      route.abort('failed');
    });

    await page.fill('input[placeholder="输入公司 ID 或名称"]', 'test_tenant');
    await page.fill('input[placeholder="您的管理员账号"]', 'admin');
    await page.fill('input[placeholder="••••••••"]', 'admin123');

    const captchaText = await page.locator('.captcha-text').textContent();
    await page.fill('input[placeholder="输入验证码"]', captchaText!);

    await page.click('button[type="submit"]');

    await expect(page.locator('.el-message')).toContainText('网络错误');
  });

  test('LC-029: 快速重复点击', async ({ page }) => {
    // Mock API 延迟响应
    await page.route('**/api/auth/login', async (route) => {
      await new Promise(resolve => setTimeout(resolve, 1000));
      route.continue();
    });

    await page.fill('input[placeholder="输入公司 ID 或名称"]', 'test_tenant');
    await page.fill('input[placeholder="您的管理员账号"]', 'admin');
    await page.fill('input[placeholder="••••••••"]', 'admin123');

    const captchaText = await page.locator('.captcha-text').textContent();
    await page.fill('input[placeholder="输入验证码"]', captchaText!);

    // 快速点击3次
    await page.click('button[type="submit"]');
    await page.click('button[type="submit"]');
    await page.click('button[type="submit"]');

    // 等待请求完成
    await page.waitForTimeout(2000);
  });
});
