> 本模板用于 blade-admin 所有功能模块的测试用例设计。
> 每个模块复制一份，替换功能相关内容即可。

1. 复制本模板到目标模块目录，如 `src/views/orders/TEST_CASES.md`
2. 将 `[模块名]` 替换为实际模块名
3. 填写各节的具体测试用例
4. 执行后更新测试状态和执行记录

## 九、浏览器截图测试规范

> **⚠️ 重要：需要从用户视角检查界面或进行交互测试时，必须使用浏览器截图测试。**

### 9.1 必须截图的场景

| 场景 | 原因 |
|------|------|
| 页面首次加载 | 检查布局、排版、样式是否正常 |
| 表单填写后 | 确认用户输入正确呈现 |
| 操作结果 | 记录操作后的界面状态 |
| 弹窗/对话框 | 确认视觉呈现 |
| 下拉菜单/展开状态 | 确认展开内容 |
| 错误提示 | 记录错误信息呈现 |
| 页面跳转 | 确认跳转目标页面 |

### 9.2 截图测试流程

**Step 1：启动浏览器并打开页面**

```bash
browser-use open http://localhost:5777/[页面路径]
```

**Step 2：获取页面元素状态**

```bash
browser-use state
```

**Step 3：执行操作或填写表单**

```bash
# 输入文本
browser-use input [元素索引] "文本内容"

# 点击按钮
browser-use click [元素索引]
```

**Step 4：截图保存**

```bash
browser-use screenshot [保存路径]
```

**Step 5：测试完成后关闭浏览器**

```bash
browser-use close
```

### 9.3 截图命名规范

```
test-screenshots/[模块名]-[测试场景]-[状态].png
```

示例：
```
test-screenshots/login-page.png
test-screenshots/login-form-filled.png
test-screenshots/dashboard-after-login.png
test-screenshots/user-menu-open.png
test-screenshots/logout-confirm.png
```

### 9.4 截图存放位置

所有测试截图存放在各模块的 `test-screenshots/` 目录下：

```
blade-admin/src/views/[模块名]/
└── test-screenshots/
    ├── [场景1].png
    └── [场景2].png
```

### 9.5 完整测试示例

```bash
# 1. 打开登录页
browser-use open http://localhost:5777/login

# 2. 截图初始状态
browser-use screenshot test-screenshots/login-page.png

# 3. 填写表单
browser-use state  # 获取元素索引
browser-use input 6 "test_tenant"
browser-use input 7 "admin"
browser-use input 4 "admin123"
browser-use input 8 "8K2M"

# 4. 截图填写后状态
browser-use screenshot test-screenshots/login-form-filled.png

# 5. 点击登录
browser-use click 11

# 6. 截图登录结果
browser-use screenshot test-screenshots/dashboard-after-login.png

# 7. 关闭浏览器
browser-use close
```

### 9.6 常用 browser-use 命令

| 命令 | 说明 |
|------|------|
| `browser-use open [url]` | 打开 URL |
| `browser-use state` | 获取页面元素和索引 |
| `browser-use screenshot [path]` | 截图保存 |
| `browser-use input [index] [text]` | 向输入框输入文本 |
| `browser-use click [index]` | 点击元素 |
| `browser-use keys [key]` | 发送键盘按键 |
| `browser-use close` | 关闭浏览器 |
