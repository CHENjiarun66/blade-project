# Blade Admin - PC 管理端

服装订单管理系统的 PC 管理后台。

## 技术栈

- Vue 3 + Vite + TypeScript
- Element Plus
- TailwindCSS v4
- Pinia
- Vue Router
- Axios
- ECharts

## 快速开始

```bash
npm install
npm run dev
npm run build
```

## 已完成模块

| 模块 | 说明 |
|------|------|
| 登录与权限接入 | 登录、权限码获取、路由守卫、菜单过滤 |
| 仪表盘 | 统计卡片与趋势图 |
| 订单管理 | 列表、详情、新建、支付状态、送货信息 |
| 配货计划 | 订单详情页支持创建、编辑、确认、取消配货计划和查看调整记录 |
| 库存管理 | 列表、入库、出库、调整、库存记录 |
| 商品管理 | 商品、颜色、尺码、分类 |
| 客户管理 | 列表、编辑、删除 |
| 系统管理 | 用户、角色、权限配置页已落地 |

```text

├── stores/         # Pinia 状态管理
```
