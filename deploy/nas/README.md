# NAS 部署入口与脚本边界

当前运维规则统一见 [NAS 生产手册](../../docs/13-NAS_PRODUCTION_OPS.md)。运行版本、TLS、备份、回退和只读检查均从该入口查，不能把旧首次部署命令当成日常发布默认流程。

| 脚本 | 原用途 / 当前限制 |
|---|---|
| deploy_app_from_local.sh | 订单重构发布专用；默认 V58，要求 V42 迁移预演证据并执行历史迁移；当前生产 V69，尚未改造成普通热修发布器 |
| deploy_from_local.sh | 首次部署或基础设施重建，可能触及数据库/Redis 容器；不用于日常应用更新 |
| docker-compose.prod.yml | 当前服务编排声明；只改应用时不得顺带重建数据库/Redis |

不要从此 README 直接启动旧迁移。普通应用、schema 和业务数据迁移的分离任务为 BE-STAB-005，见 [代码评估](../../docs/CODE_REVIEW_2026-11-02.md)。纯文档不部署应用；后续应用发布需按该次授权、测试、备份和演练证据准备。

运行目录通常为 /volume2/blade；TLS 证书和密钥只保存在 NAS 的 secrets/tls，不进入 Git 或镜像。具体路径和检查命令以现行手册及目标环境为准。
